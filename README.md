# Termak Frontend

Frontend demonstrativo da Termak, desenvolvido com Next.js, React e TypeScript.

Inclui páginas para:

- visão geral;
- oportunidades;
- diagnósticos;
- clientes;
- demos;
- tarefas;
- tracking de storage, fluxo de produtos e previsões de stock.

Os dados apresentados são apenas demonstrativos. Não existe backend nem persistência de dados.

## Executar

```bash
cd frontend
npm install
npm run dev
```

Abrir no browser:

```text
http://localhost:3001
```

O servidor também pode ser aberto noutro dispositivo da mesma rede através do endereço IP do computador:

```text
http://IP-DO-COMPUTADOR:3001
```

## Build

```bash
cd frontend
npm run build
```
